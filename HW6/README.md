## Question 1 - VAE, conditional VAE, and VQ-VAE

### Task and data

The assignment asks for image generation with a convolutional **variational autoencoder (VAE)**, class-controlled generation with a **conditional VAE (CVAE)**, and reconstruction with a **vector-quantized VAE (VQ-VAE)**.

The solution uses **Anime Face Dataset** and **Google's Cartoon Set**. Five cartoon subfolders are selected for the cartoon-face experiments. The conditional experiment uses half of each selected dataset, with separate labels for anime and cartoon faces.

### Implemented experiments

| Experiment | Method | Outputs discussed in the report |
| --- | --- | --- |
| Anime-face VAE | Convolutional encoder/decoder, Gaussian latent variables, reparameterization, reconstruction and KL losses | Loss curves and eight sampled faces |
| Cartoon-face VAE | A separately trained VAE on cartoon images | Loss curves and sampled cartoon faces |
| Conditional VAE | Add a one-hot dataset label to the encoder and decoder inputs | Generate anime or cartoon faces with the same model by changing the label |
| VQ-VAE | Replace continuous latent sampling with nearest-codebook-vector quantization | Reconstruct real anime faces and images generated by the earlier VAE |

The report describes **10 epochs** for the VAE experiment and **5 epochs** for the CVAE. The notebook also contains VQ-VAE training and reconstruction visualization code. VQ-VAE-2 is an optional assignment discussion; a VQ-VAE-2 implementation is not claimed here.

### Findings

The report presents decreasing training/reconstruction losses and qualitative face samples. It discusses how class conditioning controls the generated image domain and compares VQ-VAE reconstructions of real and VAE-generated inputs. It does **not** provide FID, Inception Score, or another quantitative image-quality benchmark, so none is inferred from the sample figures.

## Question 2 - Paired image translation with Pix2Pix

### Task and architecture

Learn a mapping between satellite imagery and the corresponding map using paired images from the **maps** dataset.

The notebook implements:

- A **U-Net generator** with downsampling, upsampling, skip connections, and dropout.
- A **PatchGAN discriminator** conditioned on the input image and either the real or generated target.
- An adversarial generator objective plus an **L1 reconstruction term**.
- Separate discriminator and generator updates, loss plots, and visual comparisons of input, reference target, and generated output after each epoch.

The loader splits each side-by-side JPEG into a **left-half input** and **right-half target**, resizes the pair to two **256 × 256 RGB** images, and normalizes values to `[-1, 1]`. Check the actual pair ordering when supplying the dataset so that the intended satellite-to-map direction matches the input and target halves.

### Training settings

| Setting | Value |
| --- | --- |
| Epochs | 10 |
| Batch size | 2 |
| Optimizer | Adam |
| Learning rate | 0.0002 |
| Adam beta 1 | 0.5 |
| L1 coefficient | 100 |

The report's final examples show recognizable large structures such as roads and rivers, with room to improve finer detail. Evaluation is qualitative; the report does not establish a numerical image-translation benchmark. The notebook's stored epoch loss values are taken from the last batch, rather than an average across all batches.
